# Student Registration System

A web application for managing student records with registration, editing, and deletion functionalities.

## Features

- Add new student records with validation
- Edit existing student records
- Delete student records
- Search functionality to filter students
- Data persistence using localStorage
- Responsive design for all screen sizes
- Form validation for all fields

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage for data persistence

## Validation Rules

- **Name**: Only letters and spaces allowed
- **Student ID**: Only numbers allowed, must be unique
- **Email**: Must be a valid email format
- **Contact**: Only numbers, 10-15 digits
- **Class**: Required field

## How to Use

1. Fill in the registration form with student details
2. Click "Register" to add the student
3. Use the "Edit" button to modify existing records
4. Use the "Delete" button to remove records
5. Search for students using the search box

## Installation

No installation required. Just open the `index.html` file in a web browser.
